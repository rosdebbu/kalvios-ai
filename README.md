# Kalvi AI (`kalvios-ai`)

An agentic AI student life companion platform that brings academics, exams, career planning, and personal finance together in one place.

## Tech Stack
- **Frontend:** React 19, TypeScript
- **Build Tool:** Vite 6
- **Icons:** Lucide React
- **Languages:** TypeScript, HTML, CSS

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
